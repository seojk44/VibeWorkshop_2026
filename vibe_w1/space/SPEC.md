# SPEC: 온라인 모닥불

## 프로젝트 이름
온라인 모닥불

## 목적
조용히 같이 불을 보며 쉬는 웹 공간. 필요할 때만 짧은 말을 건넬 수 있다. 같은 링크로 들어온 사람들이 밤 캠핑장의 모닥불 주위에 모여, 걷고 장작을 넣으며 불과 소리를 함께 느낀다.

## 이번 범위
- 밤 캠핑장 3D 화면: 어두운 하늘, 땅, 가운데 모닥불, 둘레의 나무나 텐트. 모두 코드로 그린 기본 도형으로 만든다
- 내 캐릭터 걷기: 키보드로 내 캐릭터를 캠핑장 안에서 움직인다
- 장작 넣기 행동 1개: 불 가까이에서 장작을 넣으면 불이 잠시 커졌다가 천천히 돌아온다
- 소리: 모닥불 타는 소리, 장작 넣는 소리, 소리 끄기와 켜기
- 같은 링크로 들어온 사람끼리 보이기: 같은 링크로 들어온 다른 사람의 캐릭터 위치와 장작 넣기가 내 화면에 보인다
- 짧은 채팅: 화면 아래 입력칸으로 같은 방 사람에게 짧은 글을 보내고, 캐릭터 위 말풍선으로 잠깐 보인다

## 제외 범위
- 음성 채팅, 채팅 기록 저장, 특정 사람에게만 보내기(귓속말)
- 로그인
- 결제
- 개인정보 수집 (이름, 이메일, 위치 등을 묻거나 저장하지 않는다)
- 외부 이미지와 3D 모델 파일 (png, jpg, glb, gltf, obj 등을 불러오지 않는다)

## 완료 기준
- R1. 페이지를 열면 밤 캠핑장 3D 화면이 보이고 가운데에 모닥불이 있다. (하늘색과 밝기는 R26에 따라 시간대마다 다르다)
  - 확인: index.html을 열어 어두운 하늘, 땅, 가운데 불, 둘레의 나무나 텐트가 보이는지 본다.
- R2. 모닥불이 가만히 있지 않고 일렁이며 둘레를 비춘다.
  - 확인: 10초 동안 아무것도 누르지 않고 불꽃 모양과 땅의 밝기가 계속 바뀌는지 본다.
- R3. 방향키나 WASD로 내 캐릭터가 걷고, 바닥을 클릭하거나 휴대폰 화면을 눌러도 그곳으로 걷는다.
  - 확인: 네 방향 키를 각각 눌러 움직이고 키를 떼면 멈추는지 본 뒤, 바닥 한 곳을 클릭(휴대폰은 누르기)해 그곳까지 걸어가 멈추는지 본다.
- R4. 내 캐릭터는 불 속과 캠핑장 밖으로 들어가지 못한다.
  - 확인: 불 쪽과 캠핑장 끝 쪽으로 키를 계속 눌러 캐릭터가 경계에서 멈추는지 본다.
- R5. 불 가까이에서 장작 넣기를 하면 불이 잠시 커졌다가 천천히 원래 크기로 돌아온다.
  - 확인: 불 옆으로 걸어가 화면 아래 장작 넣기 버튼을 누르고, 캐릭터가 불 쪽으로 몸을 숙이며 불이 3초 동안 커졌다가 돌아오는지 본다.
- R6. 불에서 멀리 있을 때는 장작 넣기가 되지 않는다.
  - 확인: 불에서 멀리 떨어지면 버튼이 흐려지는지 보고, 그때 눌러 불 크기와 장작 수가 바뀌지 않고 "불 가까이 가면 넣을 수 있어요"가 뜨는지 본다.
- R7. 소리 켜기 버튼을 누르면 타닥 장작 소리와 낮은 바람 소리가 들리고, 장작을 넣으면 3초 동안 타닥 소리가 커진다.
  - 확인: 페이지를 열고 화면을 누르거나 걸어도 소리가 없는지 본 뒤, 소리 켜기를 눌러 두 소리를 듣고, 불 옆에서 장작을 넣어 타닥 소리가 커지는지 듣는다.
- R8. 같은 버튼으로 소리 끄기와 켜기를 할 수 있다.
  - 확인: 버튼 글씨가 "소리 끄기"로 바뀌는지 보고, 누르면 모든 소리가 멈추는지, 다시 누르면 돌아오는지 듣는다.
- R9. 같은 링크로 들어온 다른 사람의 캐릭터가 보이고, 움직이면 내 화면에서도 움직인다.
  - 확인: 같은 링크를 두 창에 나란히 열고 한 창에서 걸어 다른 창의 캐릭터가 따라 움직이는지 본다.
- R10. 다른 사람이 장작을 넣으면 내 화면의 불도 커진다.
  - 확인: 두 창 중 한 창에서 장작 넣기를 하고 다른 창의 불도 커지는지 본다.
- R11. 나간 사람은 화면에서 사라진다. (방은 lobby부터 채우고, lobby에 8명이 넘으면 새로 온 사람은 lobby-2로 간다. lobby-2는 인원 제한이 없다)
  - 확인: 두 창 중 한 창을 닫아 남은 창에서 그 캐릭터가 몇 초 안에 사라지는지 본다.
- R12. 화면에 로그인, 결제, 이름 입력 칸이 없고, 글 입력칸은 채팅 입력칸 하나뿐이다.
  - 확인: 화면을 둘러보고 Tab 키로 이동하며 글 입력 칸이 채팅 입력칸 하나뿐인지 본다.
- R13. 외부 이미지와 3D 모델 파일을 불러오지 않는다.
  - 확인: 개발자 도구 네트워크 탭을 열고 새로고침해 png, jpg, glb, gltf, obj 요청이 없는지 본다.
- R14. 카메라가 내 캐릭터 뒤에서 따라간다.
  - 확인: 캐릭터를 돌리고 걸려 보며 화면이 계속 캐릭터 등 뒤에서 비추는지 본다.
- R15. 그날 넣은 장작 수가 화면 위에 보이고, 다시 열어도 남으며, 내 컴퓨터 날짜가 바뀌면 0부터 센다.
  - 확인: 장작을 2번 넣고 새로고침해 2가 남는지 보고, 개발자 도구 Application 탭에서 저장된 날짜를 어제로 바꾼 뒤 새로고침해 0이 되는지 본다.
- R16. 화면 위에 지금 함께 있는 사람 수(나 포함)가 보인다.
  - 확인: 창을 2개 열어 "함께 2명"이 되는지 보고, 하나를 닫아 "함께 1명"이 되는지 본다.
- R17. 들어오면 모닥불 둘레의 빈자리에서 시작해 다른 사람과 겹치지 않는다.
  - 확인: 창 3개를 차례로 열어 인형들이 불 둘레의 서로 떨어진 자리에 서는지 본다.
- R18. 연결 도구(Trystero)를 불러오지 못해도 혼자 쓰는 화면은 그대로 돌아간다.
  - 확인: 개발자 도구 네트워크 탭에서 trystero 주소를 막고 새로고침해 걷기, 장작, 소리가 되고 "혼자 있어요"가 보이는지 본다.
- R19. 60자 이내 글을 쓰고 Enter나 보내기를 누르면, 내 캐릭터 위와 다른 사람 화면의 내 캐릭터 위에 6초 동안 말풍선이 뜬다.
  - 확인: 두 창 중 한 창에서 "안녕"을 보내 양쪽 화면의 같은 캐릭터 위에 말풍선이 뜨고 6초 뒤 사라지는지 본다.
- R20. 받은 글은 글자로만 보인다.
  - 확인: `<b>굵게</b>`와 `<img src=x onerror=alert(1)>`를 보내 다른 창에서 굵게 되거나 알림창이 뜨지 않고 그 글자 그대로 보이는지 본다.
- R21. 빈 글이나 공백만 있는 글은 보내지 않고, 60자를 넘게 쓸 수 없으며, 1.5초 안에 다시 보내지 않는다.
  - 확인: 공백만 넣고 보내 말풍선이 안 뜨는지, 61자째가 입력되지 않는지, 연달아 두 번 보내면 두 번째가 안 가는지 본다.
- R22. 채팅 끄기 버튼을 누르면 입력칸이 숨고 다른 사람의 말풍선도 보이지 않으며, 다시 켜면 돌아온다.
  - 확인: 한 창에서 채팅 끄기를 누르고 다른 창에서 보낸 글이 안 보이는지 본 뒤, 다시 켜서 새 글이 보이는지 본다.
- R23. 채팅은 저장하지 않아 새로고침하면 사라지고, 입력칸에 "개인정보는 쓰지 마세요"가 보이며, 혼자 모드에서는 입력칸이 비활성이다.
  - 확인: 말풍선이 뜬 채 새로고침해 사라지는지, 입력칸 안내 문구를 보고, R18 방법으로 혼자 모드를 만들어 입력칸이 비활성인지 본다.
- R24. lobby에 이미 8명이 있으면 9번째로 들어온 사람은 들어온 뒤 5초 안에 lobby-2로 옮긴다. lobby-2가 차도 더 옮기지 않는다.
  - 확인: 인원 제한을 2명으로 낮춘 테스트 사본으로 창 3개를 차례로 열어, 세 번째 창이 5초 안에 lobby-2로 옮기고 앞 두 창의 인형이 사라지는지 본다.
- R25. 화면 위에 지금 방 이름이 사람 수와 함께 보인다.
  - 확인: "lobby · 함께 2명"처럼 보이는지, 옮긴 창에서는 "lobby-2 · 함께 1명"으로 바뀌는지 본다.
- R26. 내 컴퓨터 시각에 따라 저녁(7~20시, 낮 포함), 밤(20~4시), 새벽(4~7시)의 하늘색, 주변 밝기, 별 밝기, 불빛 세기가 달라지고, 화면을 연 채 시간대가 바뀌면 몇 초에 걸쳐 바뀐다.
  - 확인: 주소 끝 없이 열어 지금 시각의 시간대 모습인지 보고, R27의 세 주소와 비교한다. 시간대 경계(3·4시, 6·7시, 19·20시)는 Node 경계 시험으로 확인한다.
- R27. 주소 끝에 ?time=evening, ?time=night, ?time=dawn을 붙이면 그 시간대로 고정되고, 다른 값이면 무시하고 시각을 따른다.
  - 확인: 세 주소를 각각 열어 하늘색과 불빛이 서로 다른지 보고, ?time=noon은 주소 끝 없이 연 것과 같은지 본다.

## 수동 확인
1. 데스크톱 브라우저 한 곳에서 index.html을 열어 R1~R8, R14, R15, R26, R27을 차례로 확인한다.
2. 같은 링크를 창 두 개에 나란히 열어 R9, R10, R16, R19~R22를 확인하고, 세 번째 창을 열어 R17을 확인한다.
3. 창 하나를 닫아 R11을 확인한다. 인원 제한을 2명으로 낮춘 테스트 사본으로 R24, R25를 확인한다.
4. 화면 전체를 둘러보며 R12를, 개발자 도구 네트워크 탭으로 R13, R18, R23을 확인한다.
5. 창 크기를 줄였다 늘려 화면이 깨지거나 잘리지 않는지 본다.
6. 확인 결과와 실패한 R 번호를 RUNLOG.md에 적는다.

## 남은 위험
- 같은 링크 사람끼리 보이기: 서버를 만들지 않고 Trystero 0.22.0으로 공용 중계(Nostr 릴레이)를 거쳐 브라우저끼리 직접(WebRTC) 연결한다. 공용 중계가 느리거나 막히면 늦게 보이거나 연결되지 않고, 회사·학교 망이나 일부 휴대폰 망은 직접 연결을 막을 수 있다.
- IP 주소: 직접 연결 방식이라 같은 방 사람끼리 서로의 IP 주소를 알 수 있고, 공용 중계도 연결 과정을 본다. 이름은 보내지 않지만 IP는 개인정보로 볼 수 있다.
- 채팅 내용: 욕설·광고를 막거나 신고할 방법이 없고 채팅 끄기만 가능하다. 사용자가 직접 개인정보를 쓰는 것도 막을 수 없다. 고친 코드로 보내는 사람에게는 보내는 쪽 제한이 통하지 않아, 받는 쪽에서도 다듬고 60자로 자른다.
- 방 나누기: 사람 수는 방에 들어간 뒤에야 알 수 있어 처음 5초 동안 lobby 사람들이 보였다가 사라질 수 있다. 여럿이 거의 동시에 들어오면 잠깐 8명을 넘을 수 있다. 한 번 정한 방은 바꾸지 않아 lobby에 자리가 나도 lobby-2 사람은 돌아오지 않는다. lobby-2는 제한이 없어 아주 붐빌 수 있다.
- 방 공개: 방 이름(lobby, lobby-2)과 appId가 코드에 보여 누구나 들어오거나 가짜 위치를 보낼 수 있다. 받은 값은 숫자인지 보고 캠핑장 범위로 자르는 것까지만 막는다.
- 3D 화면: 외부 라이브러리 없이 3D를 그리려면 WebGL을 직접 쓰거나 CSS 3D로 흉내 내야 해 코드가 길어지고 오래된 기기에서 느릴 수 있다.
- 소리: 외부 소리 파일을 쓰지 않으면 Web Audio로 소리를 직접 만들어야 해 실제 모닥불 소리와 다르게 들릴 수 있다. 브라우저는 사용자 입력 전 자동 재생을 막는다.
- 휴대폰: 화면을 눌러 걷기만 되고, 장작 넣기와 화면을 끌어 시점 돌리기는 아직 방법이 없다.
- 사람이 많아지면 캐릭터가 겹치고, 연결 방식에 따라 움직임이 늦게 보일 수 있다.
- 장난: 말이 없어도 장작 넣기를 계속 누르면 불이 계속 커져 다른 사람의 쉼을 방해할 수 있다. 횟수 제한이 필요한지 정해야 한다.
